# Public Assets

This folder contains all public static assets for the website, including:
- Brand logos (`ANCIENTIKA MAIN LOGO.png`, etc.)
- Editorial images (`img1.jpg` - `img16.jpg`)
- Fonts (`fonts/` directory)
- Videos and music (`video.mp4`, `theme.mp3`)

## Usage
Files in this directory are served at the root path `/`.
Example: `/Logo.png` refers to `public/Logo.png`.

## Maintenance
- Replace `img1.jpg` through `img16.jpg` with high-quality editorial photos to update the site visuals.
- Do not utilize the old `assets/` folder; it has been consolidated here.
